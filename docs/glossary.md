# Glossary


<div class="glossary-layout">

### Oscillator
When you play a note on the virtual piano keyboard, it triggers an ***oscillator***. The oscillator is what generates the sound you hear!

### *Shaper*
Any individual component in the synth that produces or changes a sound. Each oscillator is a ***shaper***, and each transform has 1 or more ***shapers***.

### *Shaper Chain*
<div>

Some transforms comprise multiple shapers. Collectively, they form a ***shaper chain***.

For instance, an Envelope can have Attack, Decay and/or Release shapers, which all have their own shaper function.

</div>

### Shaper Function
The mathematicial function $f(t)$ that defines a shaper.

### *Transform*
Any effect that ***transforms*** an input audio signal, such as Distortion or an Envelope.


</div>
